# Settings

The options of all Pardona addons are in one place:

**Options › AddOns › Pardona's Addons**

The group "Pardona's Addons" has one sub-page for each installed Pardona addon. Addons that are not installed do not appear.

## Each addon has its own settings

Each addon stores its own settings. There are no shared settings between the addons: changing an option in one addon never changes another addon, and removing an addon leaves the settings of the others untouched.
