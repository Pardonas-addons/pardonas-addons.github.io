# Settings

The options of all Pardona addons are in one place:

**Options › AddOns › Pardona's Addons**

The group "Pardona's Addons" has one sub-page for each installed Pardona addon. Addons that are not installed do not appear.

The main page "Pardona's Addons" is an overview: it lists every installed Pardona addon with its version, the library version it brings ("Lib"), its status and an "Open" button. Here you can also show or hide the minimap button.

## Each addon has its own settings

Each addon stores its own settings: changing an option in one addon never changes another addon, and removing an addon leaves the settings of the others untouched. The only shared setting is the minimap button: its position and visibility apply to all Pardona addons.
