# Report a problem

Please report problems as a GitHub issue of the affected addon:

| Addon | Issues |
| --- | --- |
| Buff Reminder | [pardonas-buff-reminder/issues](https://github.com/Pardonas-addons/pardonas-buff-reminder/issues) |
| ToolTips | [pardonas-tooltip/issues](https://github.com/Pardonas-addons/pardonas-tooltip/issues) |
| UI | [pardonas-ui/issues](https://github.com/Pardonas-addons/pardonas-ui/issues) |
| Library | [lib-pardona/issues](https://github.com/Pardonas-addons/lib-pardona/issues) |

If you are not sure whether the problem is in the library, use the issues of the addon.

## What to include

- the **version** of the addon,
- the output of **`/pardona`** (see [Diagnostics](./diagnostics)),
- the output of the addon's **debug command**: `/br debug` (Buff Reminder), `/ptt debug` (ToolTips) or `/pui` (UI),
- the **full Lua error text**, if there is one,
- which **other addons** are active,
- the **steps to reproduce** the problem.

To see Lua errors, type `/console scriptErrors 1` once, or use an error addon such as BugSack.
