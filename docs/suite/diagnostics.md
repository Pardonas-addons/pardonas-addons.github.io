# Diagnostics

## `/pardona`

Type `/pardona` in chat to print a diagnosis. It shows

- the **active library version** and which addon it came from,
- **each installed Pardona addon** with its version and the library version it brings, and
- **other copies** of the library in other addons.

If an addon shows "Lib < 6", it brings an older library. That is fine: the newest installed copy is always the one in use.

Please include this output when you [report a problem](./report-a-problem).

## `/pardona show`

`/pardona show` opens the **"Pardona's Addons" overview** in the options – the same page as a right-click on the minimap button (see [Settings](./settings)).
