# Diagnostics

## `/pardona`

Type `/pardona` in chat to print a diagnosis. It shows

- the **active library version** and which addon it came from, and
- **each installed Pardona addon** with its version and the library version it brings.

Please include this output when you [report a problem](./report-a-problem).

## `/pardona show`

`/pardona show` opens the **"Pardona's Addons" overview window**.
