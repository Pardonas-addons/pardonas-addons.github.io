# Minimap button

All installed Pardona addons share **one minimap button** with the P emblem. There is never more than one, no matter how many Pardona addons you use.

## Left-click

Left-click opens a menu that lists each installed Pardona addon. Click an addon's name to open it. If an addon has its own menu entries (quick actions), they are shown indented below its name. The last entry, "Pardona settings", opens the overview.

If only one Pardona addon is installed and it has no menu entries of its own, left-click opens that addon directly.

## Right-click

Right-click opens the "Pardona's Addons" overview in the options (see [Settings](./settings)).

## Moving and hiding the button

Drag the button with the left mouse button to move it around the minimap. To hide it, clear "Show minimap button" on the overview page **Options › AddOns › Pardona's Addons**. Position and visibility apply to all Pardona addons. While the button is hidden, the menu is still available from the Addons button at the minimap.

## Addons button and LDB launchers

The same menu (left-click) and overview (right-click) are also available

- in the **addon compartment** (the Addons button at the minimap), and
- as an **LDB launcher**, for example in display addons that show LDB launchers.
