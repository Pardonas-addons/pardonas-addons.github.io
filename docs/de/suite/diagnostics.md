# Diagnose

## `/pardona`

Gib `/pardona` im Chat ein, um eine Diagnose auszugeben. Sie zeigt

- die **aktive Bibliotheksversion** und aus welchem Addon sie stammt,
- **jedes installierte Pardona-Addon** mit seiner Version und der Bibliotheksversion, die es mitbringt, und
- **weitere Kopien** der Bibliothek in anderen Addons.

Steht bei einem Addon „Lib < 6“, bringt es eine ältere Bibliothek mit. Das ist in Ordnung: Es wird immer die neueste installierte Kopie verwendet.

Bitte füge diese Ausgabe bei, wenn du [ein Problem meldest](./report-a-problem).

## `/pardona show`

`/pardona show` öffnet die **Übersicht „Pardona's Addons“** in den Optionen – dieselbe Seite wie ein Rechtsklick auf den Minimap-Button (siehe [Einstellungen](./settings)).
