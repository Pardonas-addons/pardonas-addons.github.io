# Diagnose

## `/pardona`

Gib `/pardona` im Chat ein, um eine Diagnose auszugeben. Sie zeigt

- die **aktive Bibliotheksversion** und aus welchem Addon sie stammt, und
- **jedes installierte Pardona-Addon** mit seiner Version und der Bibliotheksversion, die es mitbringt.

Bitte füge diese Ausgabe bei, wenn du [ein Problem meldest](./report-a-problem).

## `/pardona show`

`/pardona show` öffnet das **Übersichtsfenster „Pardona's Addons“**.
