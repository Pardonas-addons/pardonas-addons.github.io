# Die Suite

Pardona's Addons sind eine kleine Familie von Addons für WoW Forever, die einen gemeinsamen Look und eine gemeinsame Bedienung haben.

- **Jedes Addon funktioniert für sich allein.** Du kannst jedes Addon einzeln installieren; es bringt alles mit, was es braucht, auch die gemeinsame Pardona-Bibliothek.
- **Zusammen installiert wirken sie wie eine Suite.** Alle Pardona-Addons teilen sich
  - einen [Minimap-Button](./minimap-button) mit einem Menü für jedes installierte Addon,
  - einen Look (den Pardona-Stil),
  - eine Einstellungsgruppe „Pardona's Addons“, deren Hauptseite eine Übersicht aller installierten Pardona-Addons ist, mit jedem installierten Addon als Unterseite (siehe [Einstellungen](./settings)).
- **Jedes Addon behält seine eigenen Einstellungen.** Wenn du ein Addon entfernst, bleiben die anderen unberührt.

## Hilfe für die ganze Suite

- [Minimap-Button](./minimap-button): der gemeinsame Button und sein Menü.
- [Einstellungen](./settings): wo du die Optionen der einzelnen Addons findest.
- [Diagnose](./diagnostics): der Befehl `/pardona`.
- [Problem melden](./report-a-problem): wo du Fehler meldest und was du angeben solltest.
