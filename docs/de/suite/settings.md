# Einstellungen

Die Optionen aller Pardona-Addons findest du an einer Stelle:

**Optionen › Addons › Pardona's Addons**

Die Gruppe „Pardona's Addons“ hat für jedes installierte Pardona-Addon eine eigene Unterseite. Nicht installierte Addons erscheinen dort nicht.

Die Hauptseite „Pardona's Addons“ ist eine Übersicht: Sie zeigt jedes installierte Pardona-Addon mit seiner Version, der mitgebrachten Bibliotheksversion („Lib“), seinem Status und einem Knopf „Öffnen“. Hier blendest du auch den Minimap-Button ein oder aus.

## Jedes Addon hat eigene Einstellungen

Jedes Addon speichert seine eigenen Einstellungen: Eine Option in einem Addon ändert nie ein anderes Addon, und wenn du ein Addon entfernst, bleiben die Einstellungen der anderen unberührt. Einzige gemeinsame Einstellung ist der Minimap-Button: Seine Position und Sichtbarkeit gelten für alle Pardona-Addons.
