# Erste Schritte

## Installation

**Mit der CurseForge-App:** nach *Pardona's ToolTips* suchen und installieren. Beta-Versionen
erscheinen nur, wenn der Release-Typ Beta erlaubt.

**Von Hand:**

1. Die neueste Version von CurseForge oder GitHub herunterladen.
2. Den Ordner `PardonasToolTips` nach
   `World of Warcraft\_forever_\Interface\AddOns\` entpacken.
3. Das Spiel neu starten oder, wenn es schon läuft, `/reload` eingeben.

Die gemeinsame Bibliothek (LibPardona) ist enthalten – mehr ist nicht zu installieren.

### Optionale Addons

ToolTips läuft allein. Diese Addons ergänzen etwas, wenn sie installiert sind:

| Addon | Ergänzt |
| --- | --- |
| TradeSkillMaster | **Wert Entzaubern** und **Empfehlung** (Preise) |
| LibSharedMedia (über ein anderes Addon) | weitere Schriften in der Liste **Schrift** |
| Titan Panel oder eine andere LibDataBroker-Anzeige | einen Starter „Pardona“ mit dem Addon-Status |

## Einstellungen öffnen

- `/ptt` eingeben,
- den Pardona-Minimap-Button mit links anklicken (bei mehreren Pardona-Addons im Menü
  **ToolTips** wählen) oder
- **Optionen › Addons › Pardona's Addons › ToolTips**.

<!-- screenshot: Optionsseite ToolTips mit den Abschnitten Erscheinungsbild und Spieler & Mobs -->

Alle Änderungen wirken sofort, ohne `/reload`. Gibst du `/ptt` im Kampf ein, öffnen sich die
Optionen, sobald der Kampf vorbei ist.

## Chat-Befehle

| Befehl | Wirkung |
| --- | --- |
| `/ptt` oder `/pardonastooltips` | Optionen öffnen |
| `/ptt reset` | alle Einstellungen zurücksetzen |
| `/ptt debug` | zeigen, was das Spiel dem Addon zu lesen erlaubt (Fehlersuche) |
| `/ptt minimap` | gemeinsamen Pardona-Minimap-Button ein- oder ausblenden |
| `/ptt help` | diese Liste anzeigen |
