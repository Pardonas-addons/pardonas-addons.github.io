## Was Pardona's UI macht

**Pardona's UI** gibt Teilen der Standardoberfläche von World of Warcraft Forever die lila-goldene Pardona-Optik: dunkles Lila mit einem feinen Goldrand.

- **Nur optisch.** Positionen, Größe und Skalierung bleiben beim **Bearbeitungsmodus**. Pardona's UI verschiebt keinen Rahmen.
- **Ein Schalter je Modul.** Jeder Bereich der Oberfläche ist ein eigenes Modul, das du jederzeit ein- und ausschalten kannst, ohne `/reload`.
- **Läuft allein.** Pardona's UI braucht kein anderes Pardona-Addon. Zusammen mit Pardona's Buff Reminder oder Pardona's ToolTips tritt es als Teil der Suite auf: ein Minimap-Button und eine Einstellungsgruppe **Pardona's Addons**.

<DocShot src="/shots/ui-minimap.png" alt="Eckige Minimap im Pardona-Stil" :width="303" :height="374" />

## Was es nicht macht

- **Tooltips** bleiben unberührt – sie gehören zu **Pardona's ToolTips**.
- Keine eigenen Einheitenrahmen und kein Umfärben aller Blizzard-Fenster.
- Pardona's UI ersetzt keine anderen Oberflächen-Addons und erkennt sie auch nicht (siehe [Module](./modules)).
